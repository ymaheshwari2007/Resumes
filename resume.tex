% Arial (system font via fontspec; requires XeTeX). Ligatures=NoCommon is the
% ATS-critical bit: without it "certification" can embed as U+FB01 and a

% Known extraction quirk: Arial's cmap maps both U+003B and U+037E (Greek

% U+037E, so a ";" in body text extracts as U+037E. (\XeTeXgenerateactualtext
% breaks pdftotext under tectonic 0.17, so it is not a fix here.) The current
% text contains no semicolons; avoid adding any.

% unaffected (unlike a colour change). normalem keeps \emph italic.
